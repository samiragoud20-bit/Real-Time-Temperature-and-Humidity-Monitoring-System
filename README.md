# 🌡️ Real-Time Temperature and Humidity Monitoring System

## Project Overview

This project is a real-time environmental monitoring system developed
using an Arduino UNO, a DHT11 temperature and humidity sensor, and a
16×2 LCD display. The DHT11 sensor continuously measures the surrounding
temperature and humidity, while the Arduino processes the sensor data
and displays the readings on the LCD in real time. The system is simple,
low-cost, and suitable for learning embedded systems and IoT concepts.

## Features

-   Real-time temperature monitoring
-   Real-time humidity monitoring
-   Live display on a 16×2 LCD
-   Low-cost and easy to build
-   Accurate environmental monitoring
-   Beginner-friendly Arduino project

## Components Used

-   Arduino UNO
-   DHT11 Temperature and Humidity Sensor
-   16×2 LCD Display
-   I2C LCD Module (if using I2C LCD)
-   Breadboard
-   Jumper Wires
-   USB Cable
-   Laptop/Computer
-   Arduino IDE

## Working Principle

The DHT11 sensor senses the surrounding temperature and humidity. The
Arduino UNO reads the sensor values and processes the data. The measured
values are then displayed on the 16×2 LCD screen and updated
continuously, allowing users to monitor environmental conditions in real
time.
